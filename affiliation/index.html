Overview

This endpoint registers a new affiliation agent for the partner program. For production, the base URL changes and the API is IP-restricted to allowed addresses — endpoint paths stay the same.

Request

Endpoint
POST https://api-affiliation.gktechbd.com/api/v1/agent/register/
Headers: x-affiliation-api-key, User-Agent

Request Body

{
  "name": "John Doe",
  "dob": "1990-05-15",
  "gender": "MALE",
  "phone": "01xxxxxxxxxx",
  "partner": "PARTNER_NAME"
}
Field Details
Field Type Required Description
name string Yes Full name of the agent
dob date Yes Date of birth (YYYY-MM-DD)
gender enum Yes Gender of the agent (MALE, FEMALE)
phone string Yes Phone number (BD formatted)
partner string Yes Partner company code (PARTNER_NAME)

Response

Success (HTTP 200)
{
  "success": true,
  "data": {
  "affiliation_code": "********",
  "password": "******"
},
  "message": "OK",
  "code": 200,
  "meta_info": {}
}
Field Details
Field Type Description
affiliation_code string Unique 8-character code assigned to the new agent
password string 6-digit numeric password generated automatically for the agent

Errors

Status Code Error Description
400 Invalid phone number Phone number is invalid
400 User with this phone number already exists A user with this phone already exists
400 Invalid or missing API Key `x-affiliation-api-key` header not provided
400 Invalid or missing API Key API key is invalid

Example cURL Request

curl -X POST "https://api-affiliation.gktechbd.com/api/v1/agent/register/" \
  -H "Content-Type: application/json" \
  -H "x-affiliation-api-key: API_KEY" \
  -H "User-Agent: gk-app" \
  -d '{"name": "John Doe","dob": "1990-05-15","gender": "MALE","phone": "017XXXXXXXXX","partner": "PARTNER_NAME"}'

Tips

  1. Use a proper client library to handle retries and timeouts.
  2. Log server responses for troubleshooting errors.
  3. Do not send production API keys from client-side code.
